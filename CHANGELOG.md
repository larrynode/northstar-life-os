## [0.1.0] - 2026-08-14

### Added

- Local-first Next.js dashboard and SQLite data layer.
- Persistent projects, tasks, habits, events, inbox captures, and reviews.
- Project progress derived from task completion and idempotent daily habit
  check-ins.
- Versioned JSON CLI, safe context projections, and draft approval workflow.
- Transactional import preview/apply, exports, verified backups, and restore
  confirmation gates.
- Browser-encrypted private vault excluded from ordinary search and export.
- Explicit in-memory demo mode separated from real data.
- Five project-level Codex skills for planning, triage, reviews, and project
  health checks.
